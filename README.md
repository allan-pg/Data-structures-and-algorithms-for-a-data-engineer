# Data Structures and Algorithms for Data Engineering

This repository documents my journey of learning Data Structures and Algorithms (DSA) using Python, with a focus on concepts that are useful in Data Engineering, Analytics Engineering, and Software Development.

The goal is not only to understand how data structures and algorithms work, but also to develop stronger problem-solving skills and write more efficient code.
